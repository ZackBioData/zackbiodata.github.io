Benefits of Cloud Computing

Agility

  • Quickly deploy, test, and iterate on new ideas.

Pay-as-you-go

  • No upfront cost, pay only for what you use.
  • Stop guessing capacity — scale up/down as needed.

Economy of Scale

  • Shared resources reduce overall cost.

Global Reach

  • Access AWS services anywhere in the world.

Security

  • Built-in security features + compliance support.

Reliability

  • Consistent performance across infrastructure.

High Availability

  • Services designed to run across multiple AZs.

Scalability

  • Add/remove resources to meet demand.

Elasticity

  • Automate scaling during spikes and drops.

Fault Tolerance

  • Systems designed to continue operating when components fail.

Disaster Recovery

  • Backup, restore, and multi-region recovery solutions.

AWS Global Infrastructure

AWS global infrastructure = network of physical data centers designed for scalability, availability, and resilience.

Components

  • Regions: Geographically distinct clusters of data centers.
  • Availability Zones (AZs): One or more isolated data centers within a region.
  • Local Zones: Closer to end-users for low-latency workloads.
  • Edge Locations: Support caching (CloudFront).

Regions

  • Geographically distinct locations with one or more AZs.
  • Each region is physically isolated with its own power and water supply.
  • Pricing: Cost of services varies by region.
  • Regulations: Each region has its own compliance requirements.
  • Performance: Latency varies by region for end-users.

Key Takeaways

  • Cloud benefits = agility, scalability, elasticity, pay-as-you-go, global reach, reliability, security, fault tolerance, disaster recovery.
  • AWS global infrastructure = Regions, AZs, Local Zones, Edge Locations, designed for high availability and compliance.
  • Regions are physically isolated, but connected through AWS’s global backbone for resilience and performance.
